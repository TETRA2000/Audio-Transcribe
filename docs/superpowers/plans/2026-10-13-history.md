# History Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Save every live session and transcribed file automatically on the device, with its recaps and summary, and let the user browse, search, reread, export and delete past sessions.

**Architecture:** A SwiftData `@Model` (`HistorySession`) holds each session's metadata, a pre-folded `searchKey`, and the content (segments, recaps, summary) as one JSON blob. `TranscriptionViewModel` builds a `SessionSnapshot` at fixed save points and upserts it through a `HistorySaving` protocol (`HistoryStore` in the app). Search folds case, accents and width with `HistorySearch`. The list filters with a plain `contains` predicate, and the detail view and snippets find matches in the original text the same way. The macOS window becomes a `NavigationSplitView` with History in the sidebar. iOS gets a History sheet.

**Tech Stack:** Swift 5 language mode with `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor` (app and test targets), SwiftUI, SwiftData, Observation, Swift Testing.

**Spec:** `docs/superpowers/specs/2026-10-12-history-design.md`

### Deviations from the spec (made while planning)

- **Recap panel reuse.** `RecapView` isn't split wholesale. Its row, content and summary subviews become internal with optional actions, and a new `SavedRecapView` composes them read-only. This is the same reuse with less churn in the live panel.
- **Stepping through matches.** Next/previous (and the "N of M" count) step through **transcript** matches. Matches in the summary and recaps are highlighted but not stepped through, because they're in a separate panel. When only the summary matched, the bar says "No matches in the transcript".
- **Detail actions.** On both platforms, Copy, Share, Export and Delete for a saved session sit in one ⋯ toolbar menu.
- **Headline fallback.** With a single recap there's no overview: the scheduler only combines two or more. So the saved headline is the overview's headline, else the only recap's headline, else nothing.
- **Test seam.** The view model depends on a one-method protocol, `HistorySaving`, so tests can make saving fail.
- **"This Week"** means the last 7 days, including today.
- **Duration** is the end time of the last segment.
- **Search limits.**
  - Each transcript line is searched on its own, so a query that spans two lines doesn't match.
  - Hiragana and katakana are not folded together: こ doesn't match コ.
- **Known limitation.** Pressing Clear (or Start) while the summary is still being made after Stop drops that summary. The scheduler cancels it, and the History entry keeps the transcript and recaps saved so far.
- **List fetch.** It doesn't use `propertiesToFetch`. `contentData` uses external storage and is only read when a row builds a snippet or the detail opens.

## Review Focus

1. **Clear or a new session while the previous session's final recap is still generating.** The late recap must not be written into either the old or the new History entry, and the new session must get its own entry. → test `staleFinishDoesNotWriteIntoTheNextSession` (Task 5).
2. **Search queries with SQL wildcard or special characters** (`%`, `_`). They must match literally, not as patterns. → test `predicateMatchesWildcardCharactersLiterally` (Task 3).
3. **A query that is only whitespace.** It shows every session, not "No sessions match". → test `blankQueryMatchesEverySession` (Task 3).

```swift
import Foundation

/// Search for History: text is folded so case, accents and character width don't matter. Matches are found in
/// the original text, and snippets are cut around them.
///
/// Matching folds one original `Character` at a time, so every match maps back to whole characters of the original
/// text. `fold` works the same way, and `searchKey` (what the History list's predicate searches) is built with it,
/// so the list and the opened session agree on what matches.
nonisolated enum HistorySearch {
    /// Case-, diacritic- and width-insensitive. Compatibility normalization (NFKC) comes first, so half-width
    /// katakana with a separate voiced mark (ｶﾞ) becomes the full-width character (ガ). Japanese voiced marks are
    /// kept: か and が stay different.
    static func fold(_ text: String) -> String {
        String(text.flatMap(foldCharacter))
    }

    private static func foldCharacter(_ character: Character) -> [Character] {
        Array(String(character).precomposedStringWithCompatibilityMapping
            .folding(options: [.caseInsensitive, .diacriticInsensitive, .widthInsensitive], locale: nil))
    }

    /// The ranges of `query` in `text`, in order and not overlapping. Empty when the query folds to nothing.
    static func ranges(of query: String, in text: String) -> [Range<String.Index>] {
        let needle = Array(fold(query))
        guard !needle.isEmpty else { return [] }
        // Each folded character, with the range of the original character it came from.
        var folded: [Character] = []
        var origins: [Range<String.Index>] = []
        var index = text.startIndex
        while index < text.endIndex {
            let next = text.index(after: index)
            for character in foldCharacter(text[index]) {
                folded.append(character)
                origins.append(index..<next)
            }
            index = next
        }
        var result: [Range<String.Index>] = []
        var start = 0
        while start + needle.count <= folded.count {
            guard folded[start..<(start + needle.count)].elementsEqual(needle) else {
                start += 1
                continue
            }
            let range = origins[start].lowerBound..<origins[start + needle.count - 1].upperBound
            // A character that folds to several (ß → ss) can produce two matches inside it: keep the first.
            if let last = result.last, range.lowerBound < last.upperBound {
                start += 1
                continue
            }
            result.append(range)
            start += needle.count
        }
        return result
    }

    /// A match in one of several texts: which text, and where in it.
    struct TextMatch: Equatable {
        let text: Int
        let range: Range<String.Index>
    }

    /// Every match of `query` in `texts`, text by text.
    static func matches(in texts: [String], query: String) -> [TextMatch] {
        texts.enumerated().flatMap { index, text in
            ranges(of: query, in: text).map { TextMatch(text: index, range: $0) }
        }
    }

    /// An excerpt around a match, for a History row.
    struct Snippet: Equatable {
        /// The excerpt on one line, with "…" where it was cut.
        let text: String
        /// Where the match is in `text`.
        let match: Range<String.Index>
    }

    /// About `radius` characters either side of the first match in the first text that has one.
    static func snippet(in texts: [String], query: String, radius: Int = 40) -> Snippet? {
        for text in texts {
            guard let match = ranges(of: query, in: text).first else { continue }
            let start = text.index(match.lowerBound, offsetBy: -radius, limitedBy: text.startIndex) ?? text.startIndex
            let end = text.index(match.upperBound, offsetBy: radius, limitedBy: text.endIndex) ?? text.endIndex
            let before = (start == text.startIndex ? "" : "…") + oneLine(text[start..<match.lowerBound])
            let matched = oneLine(text[match])
            let after = oneLine(text[match.upperBound..<end]) + (end == text.endIndex ? "" : "…")
            let snippet = before + matched + after
            let lower = snippet.index(snippet.startIndex, offsetBy: before.count)
            let upper = snippet.index(lower, offsetBy: matched.count)
            return Snippet(text: snippet, match: lower..<upper)
        }
        return nil
    }

    private static func oneLine(_ text: Substring) -> String {
        text.replacingOccurrences(of: "\n", with: " ")
    }
}
```

```swift
    /// The transcript as plain text for Copy and Share. A single-source transcript is concatenated as-is: the
    /// transcriber already includes leading spaces where the language needs them (English) and none where it doesn't
    /// (Japanese). A multi-source transcript puts each segment on its own `Speaker: text` line.
    static func plainText(_ segments: [TranscriptSegment]) -> String {
        if segments.contains(where: { $0.speaker != nil }) {
            return lines(segments).joined(separator: "\n")
        }
        return segments.map(\.text).joined().trimmingCharacters(in: .whitespacesAndNewlines)
    }
```

```swift
struct SessionSnapshot: Equatable {
    var kind: SessionKind
    var language: TranscriptionLanguage
    var startedAt: Date
    /// The end of the last segment on the session's timeline.
    var duration: TimeInterval
    /// The live channels' labels in order (the microphone first). Empty for files.
    var sourceLabels: [String]
    var fileName: String?
    var content: SessionContent

    /// For the History row: the summary's headline, or the only recap's headline (a single recap is not combined
    /// into a summary).
    var headline: String? {
        content.overview?.headline ?? (content.recaps.count == 1 ? content.recaps[0].headline : nil)
    }

    var searchKey: String { HistorySearch.searchKey(fileName: fileName, content: content) }

    /// `nil` when there is no final text: nothing to read or search, so nothing is saved.
    static func make(
        kind: SessionKind,
        language: TranscriptionLanguage,
        startedAt: Date,
        fileName: String?,
        sourceLabels: [String],
        segments: [TranscriptSegment],
        recaps: [RecapEntry],
        overview: OverviewState?
    ) -> SessionSnapshot? {
        guard segments.contains(where: { !$0.text.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty }) else {
            return nil
        }
        let savedRecaps = recaps.compactMap { entry in
            entry.content.map { content in
                SessionContent.Recap(
                    windowStart: entry.windowStart, windowEnd: entry.windowEnd, isFinal: entry.isFinal,
                    headline: content.headline, keyPoints: content.keyPoints
                )
            }
        }
        let summary: RecapContent? = if case .done(let content) = overview { content } else { nil }
        return SessionSnapshot(
            kind: kind,
            language: language,
            startedAt: startedAt,
            duration: segments.map(\.end).max() ?? 0,
            sourceLabels: sourceLabels,
            fileName: fileName,
            content: SessionContent(segments: segments.map(SessionContent.Segment.init), recaps: savedRecaps, overview: summary)
```

```swift
    /// Everything a session is searched by, in the order snippets prefer: the file name, the speakers, the
    /// summary, the recaps, then the transcript one line per segment.
    static func searchableTexts(fileName: String?, content: SessionContent) -> [String] {
        var texts: [String] = []
        if let fileName { texts.append(fileName) }
        var speakers: [String] = []
        for speaker in content.segments.compactMap(\.speaker) where !speakers.contains(speaker) {
            speakers.append(speaker)
        }
        texts += speakers
        if let overview = content.overview { texts.append(overview.plainText) }
        texts += content.recaps.map(\.content.plainText)
        texts += content.segments.map { $0.text.trimmingCharacters(in: .whitespaces) }
        return texts
    }

    /// The folded text the History list searches. Texts are joined with newlines, so a query never matches across
    /// two of them.
    static func searchKey(fileName: String?, content: SessionContent) -> String {
        fold(searchableTexts(fileName: fileName, content: content).joined(separator: "\n"))
    }
```

```swift
import Foundation
import SwiftData

/// Where `TranscriptionViewModel` saves sessions. A protocol so tests can make saving fail.
protocol HistorySaving: AnyObject {
    /// Saves `snapshot` as the session `id`: inserted the first time, updated after that.
    func upsert(id: UUID, snapshot: SessionSnapshot) throws
}

/// The History store: one SwiftData container on this device (in memory for tests).
final class HistoryStore: HistorySaving {
    let container: ModelContainer
    private var context: ModelContext { container.mainContext }

    init(inMemory: Bool = false) throws {
        // An in-memory store gets a unique name, so each one is separate.
        let configuration = ModelConfiguration(
            inMemory ? UUID().uuidString : nil,
            isStoredInMemoryOnly: inMemory,
            cloudKitDatabase: .none
        )
        container = try ModelContainer(for: HistorySession.self, configurations: configuration)
    }

    func upsert(id: UUID, snapshot: SessionSnapshot) throws {
        // Encode first, so a failure leaves nothing half-written in the context.
        let contentData = try JSONEncoder().encode(snapshot.content)
        let session: HistorySession
        if let existing = try self.session(id: id) {
            session = existing
        } else {
            session = HistorySession(id: id)
            context.insert(session)
        }
        session.startedAt = snapshot.startedAt
        session.duration = snapshot.duration
        session.kindRaw = snapshot.kind.rawValue
        session.languageRaw = snapshot.language.rawValue
        session.sourceLabels = snapshot.sourceLabels
        session.fileName = snapshot.fileName
        session.headline = snapshot.headline
        session.contentData = contentData
        session.searchKey = snapshot.searchKey
        do {
            try context.save()
        } catch {
            context.rollback()
            throw error
        }
    }

    func session(id: UUID) throws -> HistorySession? {
        var descriptor = FetchDescriptor<HistorySession>(predicate: #Predicate { $0.id == id })
        descriptor.fetchLimit = 1
        return try context.fetch(descriptor).first
    }

    /// What the History list shows for `query`.
    func fetch(matching query: String) throws -> [HistorySession] {
        try context.fetch(Self.descriptor(matching: query))
    }

    func delete(_ ids: Set<UUID>) throws {
        let ids = Array(ids)
        let sessions = try context.fetch(FetchDescriptor<HistorySession>(predicate: #Predicate { ids.contains($0.id) }))
        for session in sessions {
            context.delete(session)
        }
        do {
            try context.save()
        } catch {
            context.rollback()
            throw error
        }
    }

    /// Newest first. A query that isn't blank keeps the sessions whose `searchKey` contains it, folded the same way.
    /// SwiftData's `contains` is a literal, case-sensitive match, so both sides must be folded.
    static func descriptor(matching query: String) -> FetchDescriptor<HistorySession> {
        let key = HistorySearch.fold(query.trimmingCharacters(in: .whitespacesAndNewlines))
        let predicate: Predicate<HistorySession>? = key.isEmpty ? nil : #Predicate { $0.searchKey.contains(key) }
        return FetchDescriptor(predicate: predicate, sortBy: [SortDescriptor(\.startedAt, order: .reverse)])
    }
}
```

```swift
    /// Starts a History entry for the session about to be recorded or transcribed. The entry is created at the
    /// first save that has final text.
    func beginHistorySession(startedAt: Date, fileName: String?) {
        historyID = nil
        historyStartedAt = startedAt
        historyFileName = fileName
        historyLanguage = language
    }

    /// Saves the session on screen to History: a new entry the first time it has final text, then updates to it.
    /// Does nothing before `beginHistorySession` or after `clear`.
    func saveToHistory() {
        guard let history, let startedAt = historyStartedAt else { return }
        guard let snapshot = SessionSnapshot.make(
            kind: historyFileName == nil ? .live : .file,
            language: historyLanguage,
            startedAt: startedAt,
            fileName: historyFileName,
            sourceLabels: channels.map(\.label),
            segments: segments,
            recaps: recap.entries,
            overview: recap.overview
        ) else { return }
        let id = historyID ?? UUID()
        do {
            try history.upsert(id: id, snapshot: snapshot)
            historyID = id
            historyWarning = nil
        } catch {
            historyWarning = "Couldn't save this session to History. \(error.localizedDescription)"
        }
    }

    /// One ticker step while recording: a recap if one is due, and a History checkpoint.
    func tickRecaps(now: TimeInterval) {
        recap.tick(now: now, segments: segments)
        saveToHistory()
```

```swift
import SwiftUI

/// Marks search matches in text.
enum SearchHighlight {
    /// `text` with a light background on each range, and a stronger one on `current`.
    static func marked(_ text: String, ranges: [Range<String.Index>], current: Range<String.Index>? = nil) -> AttributedString {
        var attributed = AttributedString(text)
        for range in ranges {
            guard let marked = Range(range, in: attributed) else { continue }
            attributed[marked].backgroundColor = range == current ? Color.yellow : Color.yellow.opacity(0.35)
        }
        return attributed
    }
}
```

```swift
/// Search matches to mark in a transcript.
struct TranscriptHighlight: Equatable {
    /// Every match, in order. `TextMatch.text` is the segment's index, and ranges are in `TranscriptLines.displayText`.
    let matches: [HistorySearch.TextMatch]
    /// The index in `matches` of the match to show.
    let current: Int
}

/// A transcript: finished lines with their times (and speakers, when there are several sources), then the
/// in-progress text. Search matches are marked, and the current one is scrolled into view.
struct TranscriptLines: View {
    let segments: [TranscriptSegment]
    var volatileLines: [VolatileLine] = []
    /// The speaker shown in the accent color (the first source). Other speakers are orange.
    var primarySpeaker: String?
    var highlight: TranscriptHighlight?
    /// A live transcript follows new text at the bottom. A saved one opens at the top.
    var followsEnd = true

    /// The text a line shows, which is also what search matches are found in.
    static func displayText(_ segment: TranscriptSegment) -> String {
        segment.text.trimmingCharacters(in: .whitespaces)
    }

    var body: some View {
        ScrollViewReader { proxy in
            ScrollView {
                LazyVStack(alignment: .leading, spacing: 8) {
                    ForEach(Array(segments.enumerated()), id: \.element.id) { index, segment in
                        transcriptRow(segment, index: index)
                            .id(segment.id)
                    }
                    ForEach(volatileLines) { line in
                        HStack(alignment: .firstTextBaseline, spacing: 8) {
                            if let label = line.label {
                                speakerTag(label)
                            }
                            Text(line.text.trimmingCharacters(in: .whitespaces))
                                .foregroundStyle(.secondary)
                        }
                    }
                }
                .padding()
            }
            // Keep the end of the transcript in view as lines arrive, instead of scrolling to a marker on every update:
            // the marker sat inside the padding, which left the newest text partly hidden, and the onChange action on
            // the in-progress text hit SwiftUI's "tried to update multiple times per frame" limit.
            .defaultScrollAnchor(followsEnd ? .bottom : .top)
            .defaultScrollAnchor(followsEnd ? .bottom : nil, for: .sizeChanges)
            .onChange(of: highlight, initial: true) {
                guard let highlight, highlight.matches.indices.contains(highlight.current) else { return }
                let segment = segments[highlight.matches[highlight.current].text]
                withAnimation { proxy.scrollTo(segment.id, anchor: .center) }
            }
        }
    }

    private func transcriptRow(_ segment: TranscriptSegment, index: Int) -> some View {
        HStack(alignment: .firstTextBaseline, spacing: 8) {
            Text(segment.formattedStart)
                .font(.caption.monospacedDigit())
                .foregroundStyle(.secondary)
                .frame(width: 56, alignment: .leading)
            if let speaker = segment.speaker {
                speakerTag(speaker)
            }
            Text(lineText(segment, index: index))
                .textSelection(.enabled)
        }
    }

    private func lineText(_ segment: TranscriptSegment, index: Int) -> AttributedString {
        let text = Self.displayText(segment)
        guard let highlight else { return AttributedString(text) }
        let current = highlight.matches.indices.contains(highlight.current) ? highlight.matches[highlight.current] : nil
        let ranges = highlight.matches.filter { $0.text == index }.map(\.range)
        return SearchHighlight.marked(text, ranges: ranges, current: current?.text == index ? current?.range : nil)
    }

    /// A small colored label: the primary speaker uses the accent color, others orange.
    private func speakerTag(_ speaker: String) -> some View {
        let color: Color = speaker == primarySpeaker ? .accentColor : .orange
        return Text(speaker)
            .font(.caption.weight(.semibold))
            .foregroundStyle(color)
            .padding(.horizontal, 6)
            .padding(.vertical, 2)
            .background(color.opacity(0.15), in: .capsule)
    }
```

```swift
import SwiftUI
import UniformTypeIdentifiers

/// An export the user asked for. Combined goes through a save panel. Separate and both go into a folder the user picks.
struct ExportRequest: Identifiable, Equatable {
    let id = UUID()
    let kind: ExportKind
}

/// The Export menu items: one for a single-source transcript, three for a multi-source one.
struct ExportMenuItems: View {
    let hasSeparateSources: Bool
    @Binding var request: ExportRequest?

    var body: some View {
        if hasSeparateSources {
            Button("Export Combined…", systemImage: "square.and.arrow.down") { request = ExportRequest(kind: .combined) }
            Button("Export Separate…") { request = ExportRequest(kind: .separate) }
            Button("Export Combined + Separate…") { request = ExportRequest(kind: .combinedAndSeparate) }
        } else {
            Button("Export…", systemImage: "square.and.arrow.down") { request = ExportRequest(kind: .combined) }
        }
    }
}

extension View {
    /// Presents the save panel or folder picker for each `request`, then writes the files `makeFiles(kind, baseName)`
    /// returns. Existing files are never overwritten.
    func transcriptExporter(
        request: Binding<ExportRequest?>,
        makeFiles: @escaping (ExportKind, String) -> [ExportFile],
        onFailure: @escaping (Error) -> Void
    ) -> some View {
        modifier(TranscriptExporterModifier(request: request, makeFiles: makeFiles, onFailure: onFailure))
    }
}

private struct TranscriptExporterModifier: ViewModifier {
    @Binding var request: ExportRequest?
    let makeFiles: (ExportKind, String) -> [ExportFile]
    let onFailure: (Error) -> Void

    @State private var isExportingFile = false
    @State private var document = PlainTextDocument(text: "")
    @State private var fileName = ""
    @State private var isChoosingFolder = false
    @State private var folderKind = ExportKind.separate

    func body(content: Content) -> some View {
        content
            .onChange(of: request) {
                guard let request else { return }
                self.request = nil
                if request.kind == .combined {
                    guard let file = makeFiles(.combined, TranscriptExporter.defaultBaseName(for: Date())).first else { return }
                    document = PlainTextDocument(text: file.text)
                    fileName = (file.name as NSString).deletingPathExtension
                    isExportingFile = true
                } else {
                    folderKind = request.kind
                    isChoosingFolder = true
                }
            }
            .fileExporter(isPresented: $isExportingFile, document: document, contentType: .plainText, defaultFilename: fileName) { result in
                if case .failure(let error) = result, (error as? CocoaError)?.code != .userCancelled {
                    onFailure(error)
                }
            }
            .fileImporter(isPresented: $isChoosingFolder, allowedContentTypes: [.folder]) { result in
```

```swift
import Foundation

/// How History rows and sections describe sessions.
enum HistoryFormat {
    /// The list's sections, newest first.
    enum DayGroup: String, CaseIterable {
        case today = "Today"
        case yesterday = "Yesterday"
        /// The last 7 days, today included, apart from today and yesterday.
        case thisWeek = "This Week"
        case earlier = "Earlier"
    }

    static func group(for date: Date, now: Date, calendar: Calendar = .current) -> DayGroup {
        if calendar.isDate(date, inSameDayAs: now) { return .today }
        if let yesterday = calendar.date(byAdding: .day, value: -1, to: now), calendar.isDate(date, inSameDayAs: yesterday) {
            return .yesterday
        }
        if let weekStart = calendar.date(byAdding: .day, value: -6, to: calendar.startOfDay(for: now)), date >= weekStart {
            return .thisWeek
        }
        return .earlier
    }

    /// The row's first line: the month, day and time, with the year when it isn't this year.
    static func title(_ date: Date, now: Date = Date(), calendar: Calendar = .current) -> String {
        var style = Date.FormatStyle(date: .omitted, time: .omitted, calendar: calendar, timeZone: calendar.timeZone)
            .month(.abbreviated).day().hour().minute()
        if !calendar.isDate(date, equalTo: now, toGranularity: .year) {
            style = style.year()
        }
        return date.formatted(style)
    }

    /// "< 1 min", "12 min", "1 h", "1 h 5 min".
    static func duration(_ seconds: TimeInterval) -> String {
        let minutes = Int(seconds) / 60
        guard minutes > 0 else { return "< 1 min" }
        let hours = minutes / 60
        let rest = minutes % 60
        if hours == 0 { return "\(minutes) min" }
        return rest == 0 ? "\(hours) h" : "\(hours) h \(rest) min"
    }

    /// The row's last line when not searching: the duration, then the sources or "File".
    static func details(for session: HistorySession) -> String {
        let source = session.kind == .file ? "File" : session.sourceLabels.joined(separator: " + ")
        return "\(duration(session.duration)) · \(source)"
    }
}
```
